# 报告统一写作与排版规则

本轮依据：本人已认可7页排版样张，并在2026-11-27要求交叉引用、真实期刊文献及URL、首次缩写全称、图表编号加粗、正文与题注分别使用完整／缩写标签。以下是本项目统一制作约定。教师明示内容和篇幅优先；这些细节不冒称TPAMI的唯一官方规定。

## 1. 文档与结构

- 英文报告；A4单栏、四边25mm、Times New Roman正文11pt、双倍行距。正文基线22pt；图注、表格与参考文献以11pt设计。标题、页眉页脚、数学上下标按相应层级设置。
- 一级标题罗马编号、居中、真正small caps；二级标题字母编号、左对齐、斜体。总标题保留正常大小写。
- 教师六章为Introduction、Problem Statement、Data Description and Preparation、Methodology、Experiment and Discussion、Conclusion。前有封面和独立一页Executive Summary；后设Appendix — References。
- 全部内容目标20–25页，现定23页合稿预算，封面、摘要、图表和文献均计入。教师原指南p.2明确图表在正文、文献在附录计页。May 1旧日期不用；正式截止沿已核Canvas记录12/6 23:59 HKT，定稿前核最新通知。
- 段内不以粗体强调一般论点；下文规定的图表题注标签是本人本轮明确要求的例外。

## 2. 缩写、命名与符号

- 摘要和正文各自首次出现缩写时，写完整名称（缩写），之后统一缩写。只出现一两次的词可直接用全称；不用缩写表代替首次定义。
- 图表须能独立读懂，图注／表注中首次使用的缩写另解释；单位和统计符号也须就地说明。
- 正例：logistic regression (LR)；random forest (RF)；exploratory data analysis (EDA)；average precision (AP)；area under the receiver operating characteristic curve (ROC AUC)；cross-validation (CV)。
- AP不得改称梯形积分的PR AUC；二者计算口径分开。F0/G1/G2是配置代号，应第一次列清字段和run，而非仅写一个字母。
- L2、C、K、p等不是“有英文缩写就够”：要说明用途／含义。例：K为所选客户人数，C是逆正则化强度。对数变换说明log1p(x)=log(1+x)，并注明实际应用到哪些列。
- 描述群名用易懂英文／中文说明，避免只写“久单群”等内部简称。无新证据时不用“高价值”“忠诚”等超出画像的标签。

## 3. 正文交叉引用与题注

| 对象 | 正文写法 | 题注／标签写法 |
|---|---|---|
| 图 | Figure 1；Figures 1 and 2 | **Fig. 1.** 后接正常字重说明，放图下 |
| 表 | Table I；Tables I and II | **Table I.** 后接正常字重说明，放表上 |
| 公式 | Equation (1)；Equations (1)–(3) | 居中公式，右侧(1)，不另加题注 |
| 章节 | Section IV；Section IV-A | 自动生成章节编号 |
| 子图 | Figure 2(a) | 面板(a)、(b)；共享图号，不把每面板另计一图 |

题注中只加粗“标签＋编号”，例如**Fig. 1.**、**Table I.**；正文Figure 1／Table I保持正常字重。图用阿拉伯数字，表用罗马数字，全文各自连续。题注Table使用正常首字母大写；这是本次对先前TABLE样张的具体修订。

每张图、表、编号公式均在正文明确引用，通常先解释问题／读法，再呈现对象。不要仅写“如下图”“上表”“这个结果”。图和表的结论写进正文，不能让题注代替讨论；正文也不逐字重抄全部表格。

最终LaTeX使用label/ref/eqref/cite自动引用；Word草稿可用可编辑字段。初稿不必写LaTeX，可用稳定资产ID：Figure [F01]、Table [T-R1-01]、Equation [E-R3-01]、citation [saito2015]。组员同时交ID清单，6号合稿时转换成自动编号；这些方括号资产标记不留在最终PDF。

## 4. 论文来源与真实性

- 用于支持学术论据的论文采用正式发表在可信、可识别期刊的版本。优先方法原始文献和与论点直接相关的正式期刊研究，不以arXiv、预印本、博客或AI回答充当学术论文证据。
- 数据集、软件参数、代码和本组实验分别引用数据发布者、官方软件文档、实际版本／代码及本组结果。它们属于原始资料，不伪装成期刊论文，也不要求将每个数据来源硬换成期刊。
- 某算法的原始论文若是会议论文，先如实注明其类型，不将其包装成期刊；本批期刊池不会据此编造“CatBoost期刊原论文”。CatBoost参数说明用官方文档，梯度提升一般原理可引用Friedman正式期刊文献，两种支持范围分开。
- 每篇拟用论文核作者、题名、期刊、年份、卷期、页码／文章号和DOI；给出可点击的https DOI URL及出版者页。DOI、标题和期刊须互相匹配；搜索摘要、搜索结果页或一串似真的DOI不足以证明所引论点。
- 实际阅读支持论点的正文／方法／结果位置，记录页码、章节或表图编号。存在性核验与内容支持核验分开；只读摘要就写“摘要核读”，不能称全文核验。付费墙无法访问时记录缺口，改选可合法核读的正式来源，或只作摘要确实支持的有限表述。
- 检查出版者页面的更正／撤稿／版本提示。存在勘误按修订理解；撤稿文章不用作正面证据。经典旧文用原期刊发表年份，网站后续数字化年份不替换论文年份。
- [10篇期刊候选池](references/README.md)已核DOI与期刊元数据，并有支持范围和注意事项；它是候选库，不是要求把10篇全部塞入正文，也不代表已逐篇读完全文。

## 5. 引用与参考文献

- 正文按首次出现顺序使用[1]、[2]等，重复来源复用同号。合稿用BibTeX统一排序，组员不各自创建互相冲突的最终编号。
- 引用放在其支持的事实／方法／判断附近；数据表、外部重绘图和公式的来源在题注或相邻解释明确。只有段末一个引用时，须能辨明它支持哪些句子。
- 自己的实验结果引用本组对应结果表／图／run；不能拿一篇方法论文替本组50/49/48结果作来源。反过来，运行成功也不能替代方法定义的文献。
- 改写他人思想仍引用；直接引语尽量少，用引号和具体位置，不改写几词后当作自己的结论。不得编作者、页码、DOI或未读的结果。
- 正文每条引用有文末条目，文末每条条目在正文实际使用；最终不留孤立条目、citation占位、[?]、??或本地磁盘路径。每篇学术论文保留DOI URL，网页资料保留官方URL和访问日期，URL以可读、可点击方式输出。

## 6. 图与可视化

- 优先矢量PDF/SVG；同时交绘图源代码／可编辑图源与输入数据，附PNG预览。截图不能代替可编辑图表或数据。照片等确需位图时按实际印刷尺寸至少300dpi，细线／文字图优先矢量。
- 图内标签按最终排版尺寸约11pt设计；检查坐标、图例、面板标识、误差线和注释。不要先画超大图再缩到字太小。
- 同一个模型／客户群在全篇保持同一颜色与名称；用标签、线型或形状辅助区分。计数柱状图从0起；必要局部放大须明确标轴和目的。误差线说明是CI、SD、范围还是其他量。
- 题注交代对象、时间／窗口、样本、分母、容量K、指标单位、关键比较条件及来源。原图只作尺寸／标签适配时保留原始版本及输入，不改数字来配叙述。

## 7. 表、精度与公式

- 表交Excel/CSV和可编辑正文表；列头写单位，计数整数，比例明确0–1还是百分比，金额明确币种和商品金额／销售额／利润口径。
- 本项目正文展示统一：人数整数；Precision/Recall百分比三位；AP/ROC AUC四位；p值三位或小值用科学计数；金额两位。计算用未舍入数据，表、图、正文重复指标保持一致；口语化“约1.7%”保留“约”。已有来源原精度可在底表保留。
- 明确缺失值为NA且解释原因；“未计算”不写0，数值舍入为0不写成真实概率为0。报告样本数、正例数和比较条件，避免只有漂亮的单一均值。
- 公式用Word公式或LaTeX数学，不能交截图。首次定义符号、取值／单位与适用对象；正文说明公式解决什么问题，必要时给一处与实际表一致的数值例子。变量、向量、下标和函数名全篇一致。
- 对外部已有公式给恰当来源；本组定义的指标写明定义。准确描述实现：不能给一种目标函数的公式却运行另一种模型。

## 8. 实验身份与论证

- 每个重要结果能回到run、训练/开发/评价窗口、N/正例数、输入、参数、预处理、K及保存的表图。内部登记文件与必要的正文协议分开，SHA/核验脚本和管理回执不塞进正式正文。
- 同条件比较共用对象、标签、窗口、容量和指标。新G1/G2是11/26额外开发比较50/49/48；旧R3、H04、概率/价值扩展分开，不因为结果同为50就当成同一权重。
- 后期模型冻结检查按实际记录披露已见／探索历史，不据已看过结果重选模型再称“盲测”。群CV说明固定群映射条件；不写成已做严格嵌套聚类CV。
- 类别不平衡说明实际balanced权重，分数排序与概率校准分开。指标区别：更高ROC AUC不必然带来更多固定K命中；未显著不等于等效；描述关联不等于干预因果。
- 保留不利月份和无提升结果。名单容量、内容方案和业务成本假设逐项说明；商品金额不是利润，内容试验提案不是已执行试验。六岗原贡献与本人借助Codex的新增修补分开记录。

## 9. 交件与合稿验收

所有人按[统一交件模板](DELIVERY-TEMPLATE.md)交英文文字、公式、数据表、图源、资产与引用清单，不要求LaTeX。每人先自核其负责数字／来源与图文，实际检查人据实填；不因AI生成或脚本通过就写“已全部核实”。最终一次独立抽样核高风险段落和图表，发现问题只定向修复。

合稿检查：六章/封面/一页摘要齐；页数/字号/行距对；首次全称齐；图表公式引用无孤项；题注标签加粗且正文全字；DOI与URL真实；所引段落支持论点；所有数字同run同精度；图表可读；结果与提案地位清楚；成员身份和真实AI用途说明齐。正式Canvas提交仍由本人确认与执行。
