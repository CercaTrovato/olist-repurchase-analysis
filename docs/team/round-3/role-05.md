# 5 号 · 独立核验与名单差异

[共同规则](README.md) · [当前进度](../current-status.md)

本轮要独立判断新方法是否更好，以及收益来自群内排序还是更多名额。已有 H06 一月46→50的验收保留，本轮核新增方案。

按客户与日期一对一连接H02标签、H04分数、H05群号，报告重复/漏配/样本变化。自己从分数按共同规则重排名单，核全局2937、久单单独79及5/10/20容量。分别报每群客户、正例、入选、命中、精确率和召回率，零名额的比例按缺定义处理。

对每个新旧对照，列共同入选、换入、换出及各自命中。可以自主选择合理的不确定性分析，说明样本单位、是否重训、客户重复与时期重叠。已拟合分数的客户重采样反映条件波动，随机种子范围也需按其含义解释。结论必须与数据的有效性范围一致。

建议交 acceptance.md、comparison-round3.csv、group-comparison.csv、paired-list-changes.csv、复算脚本，以及容量/群内固定名额/不确定性图。每张图给数据与图注，指出是否足以支持6号采用。
