## 这版采用哪些结果

当前 R3 F0 原八字段加权逻辑回归，十月全体 21,160 人拟合、无独立校准集；一月 29,368 人／230 位复购者，Top10% 为 2,937 人。未加权命中 46，加权 50；测试过的加权配送、评价、加群号、分群模型分别为 48、46、50、49。

当前加权全局名单的三群席位为 2,190／73／674，命中 21／2／27。久单群另固定 79 人是另一项诊断，未加权 1、加权 2；不能混用旧全局 79 席或旧画像。

不把加权原始 score 当自然概率，不将一月叫盲测，不用原错误区间图；不把 2 号未测试的新字段组说成已证明无效。B 的校准、CatBoost、价值模型和三期结果不混入本版主结果。
