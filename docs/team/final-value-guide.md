# 经理怎样使用全体概率和客户价值

先看目标，再选容量。全部合格客户都有概率和价值分，经理无需被规定只能看10%。

|目标/规则|实际含义|边界|
|---|---|---|
|p|优先可能复购的人|检验全体LL/Brier/校准/AP，不是个体保证|
|p×F×M|偏好更可能买、历史买得多且金额高的人|F/M是历史六自然月；F×M重复强调频次，分数不是预计货币|
|p×max(F−1,0)×M|字面“复购次数”敏感性|Jan28,665位单单零分，全部12,330久单零分，群内只能破平|
|p×发生购买条件下未来90天商品总额预测|直接估计未来90天商品额|小正例训练、重尾、跨期偏移，仍会高估/低估；不等于利润或增量|

预定容量1/2/5/10/20/50/100%都已比较。100%自然包含全部已观察复购和商品额，精确率等于群体发生率；排序不改变100%端点，也不证明全量预测失败。10%可与既有项目同容量结果比较。
