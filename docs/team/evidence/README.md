# 首轮交付结果与图表

[当前进度](../current-status.md) · [回项目首页](../../../README.md)

截至 2026-11-10，这里公开的是首轮交件中的汇总。按 H02–H06 顺着看，可以从客户样本走到验证名单和各群漏判。

## 团队实际交付

| 编号 | 对照文件 | 怎样读 |
|---|---|---|
| H02 | [三期样本与覆盖](h02-cohorts.csv) | 每行一个分析日。训练 21,160 人中 211 人复购，验证 29,368 人中 230 人复购，四月为已见探索。 |
| H03 | [月度订单覆盖](h03-monthly-coverage.csv) | 每行一个月份，分开统计下单、批准和合格批准事件。2018 年 9 月记录很少，尾部窗口要核覆盖。 |
| H04 | [验证名单比较](h04-ranking.csv) | 每行一个方法，四种方法各取 2,937 人，团队逻辑回归命中 46，最近购买优先命中 30。 |
| H05 | [三群画像](h05-cluster-profile.csv) · [初始化稳定性](h05-stability.csv) | 每群先看人数和历史特征。稳定性表只记录更换种子的结果。 |
| H06 | [三个群的验证误差](h06-segment-errors.csv) | 全局名单按群拆分。群 1 有 90 位复购者，逻辑回归选 17 人、命中 0。新版前后对照待交。 |

分群画像中，久单群过去买过运动休闲品类的有 1,114／12,330 人，整体验证客户为 2,499／29,368。约 9.03% 对 8.51%，差距较小，可以据此提出内容试验，响应要另测。[品类人数与分母](h05-category-example.csv)

交接说明给出的命令是 `python scripts/run_h05.py`。脚本本体未随包，待 4 号补可运行入口和匹配的代码、数据版本。
