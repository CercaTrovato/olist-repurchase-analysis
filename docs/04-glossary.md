# 人话术语表

按需要查，不用一次背完。建议先理解“特征、标签、时间窗口、训练／验证／测试、分类、聚类”这几个词，再看评价指标。

## 数据和购买行为

| 术语 | 英文／代码 | 人话解释与本项目例子 |
|---|---|---|
| 数据集 | Dataset | 按一定方式收集的一组记录；这里是 Olist 订单及相关表 |
| 行／列 | Row / Column | 行是一条记录，列是一项属性；一行明细不等于一个客户 |
| 表格对象 | DataFrame | pandas 放在内存里的表，可以筛选、连接和汇总 |
| 粒度 | Grain | 一行究竟代表什么：订单、商品明细还是客户快照 |
| 主键 | Primary key | 唯一辨认一行的编号，例如订单表的 order_id |
| 外键 | Foreign key | 指向另一张表的编号，例如明细里的 order_id |
| 复合键 | Composite key | 单列不够，用两列一起辨认；订单号＋明细序号 |
| 连接 | Join / merge | 按编号把相关表拼起来；一对多时可能放大行数和金额 |
| 聚合 | Aggregation / groupby | 多条记录汇成一条，例如把一个人的订单金额相加 |
| 独立买家编号 | customer_unique_id | 跨订单追踪匿名买家；不是保证识别到现实自然人的身份证 |
| 客户记录编号 | customer_id | 用来连接订单与客户表；同一买家可能有多个这种编号 |
| 有效订单 | Eligible order | 按明确条件纳入的订单；本分类实验是已批准且商品金额为正 |
| 已观察复购 | Observed repurchase | 在指定后续窗口又看到订单；不代表完整生命周期 |
| 复购比例 | Repurchase rate | 后续复购客户数／被观察客户数；必须说明窗口和样本 |
| 最近购买间隔 | Recency / R | 距最近一笔历史订单多久；不是流失时长 |
| 购买频次 | Frequency / F | 窗口内不同订单数；不是商品明细数 |
| 消费金额 | Monetary / M | 窗口内商品金额合计；不是利润或 CLV |
| 客单价 | Average order value | 商品金额／订单数；不是平均商品单价 |
| 客户生命周期价值 | CLV | 整个客户关系中预期贡献的价值，通常涉及利润、时间与成本；当前数据不足以直接估计完整 CLV |

## 分析与建模

| 术语 | 英文／代码 | 人话解释与本项目例子 |
|---|---|---|
| 探索性分析 | EDA | 先检查数据、分布和关系，提出值得检验的问题 |
| 特征 | Feature / X | 预测时已经知道的输入，例如过去消费和购买次数 |
| 标签／目标 | Label / y | 较早案例中已经发生、可供模型学习的答案：未来90天是否复购 |
| 特征工程 | Feature engineering | 把原始订单整理成可用的客户输入，并解释每项如何计算 |
| 分类 | Classification | 学习输入与已知标签的关系，再给新的样本预测分数或类别 |
| 聚类 | Clustering | 不用复购答案，根据输入特征的相似性自动分组 |
| 客户画像 | Customer profile | 对一群人的观察特征做清楚描述；名字必须来自证据 |
| K-means | K-means | 指定 K 个群中心，交替分配最近客户、更新中心，直到停止；受尺度和初始化影响 |
| 群数 | K | 希望分几组；不是模型自动证明存在的真实客户类型数量 |
| 随机种子 | Random seed | 固定随机过程的起点，方便复现；不等于结果可靠 |
| 标准化 | Standardisation | 把数值放在可比尺度上，避免金额因为数值大而主导距离 |
| 对数变换 | log1p | 对大数压缩得更多；log1p(x) 表示 log(1+x)，可用于含零的非负数据 |
| 类别编码 | One-hot encoding | 每个类别成为一个是／否列，避免强加“地区1比地区2小”的假次序 |
| 逻辑回归 | Logistic regression | 将特征加权组合为分数，再得到二分类输出；这里并不是预测连续房价的线性回归 |
| 决策树 | Decision tree | 按条件一层层分支，例如购买次数是否超过某值 |
| 随机森林 | Random forest | 汇总很多棵有差异的树，减少只依赖一棵树的不稳定 |
| 提升树 | Boosting | 后面的树逐步纠正前面的误差；CatBoost、HistGradientBoosting 属于此类 |
| 类别权重 | Class weight | 训练时给某类错误更大代价；不是把稀少类别变成更多真实客户 |
| 特征重要性 | Feature importance | 模型使用某变量的程度或移除变量后的变化；不同定义数值不同，也不等于因果重要性 |
| 交互特征 | Interaction | 表达两个特征一起出现的情形，例如购买频次与最近活跃情况的组合 |
| 群组标签 | Cluster label | 组0、组1等编号；编号自身没有大小和业务顺序 |

## 时间与验证

| 术语 | 英文 | 人话解释 |
|---|---|---|
| 客户快照 | Snapshot | 把时钟停在某天，只整理那时已知的客户情况 |
| 历史窗口 | Lookback window | 从预测日向前取多长时间的数据，例如六个月 |
| 结果窗口 | Outcome window | 从预测日向后观察多久，例如90天 |
| 右删失／观察不完整 | Right censoring | 数据结束了，但某客户未来窗口还没走完；不能简单当不复购 |
| 训练集 | Training set | 用来让模型学习参数 |
| 验证集 | Validation set | 用来选模型、参数和候选特征 |
| 测试集 | Test set | 方法固定后才用于评价的数据，不应用来反复改方案 |
| 时间留出 | Temporal holdout | 用较早时期开发、较晚时期测试，模拟过去预测未来 |
| 信息泄漏 | Leakage | 在过去做决定时用到了当时不可能知道的信息 |
| 过拟合 | Overfitting | 记住了某批数据的细节，换数据后表现下降 |
| 基准方法 | Baseline | 一个足够简单的对照，如按最近购买时间排序 |
| 消融比较 | Ablation | 拿掉或加入某一部分，检查效果变化；需保持其他条件一致 |
| 重抽样 | Resampling | 换一批样本重新分析，检查结果是否受抽样影响 |
| 置信区间 | Confidence interval | 用合理统计方法表达估计的不确定性；当前小实验尚未计算 |

## 指标与商业解释

| 术语 | 英文 | 人话解释 |
|---|---|---|
| 正样本 | Positive | 本项目中未来90天观察到复购的客户 |
| 类别不平衡 | Class imbalance | 复购客户远少于未观察到复购的客户 |
| 精确率 | Precision | 选出来的人中有多少真的复购 |
| 召回率 | Recall | 所有实际复购者中找到了多少 |
| 前10%名单 | Top 10% | 按分数排序取前一成，不是分数必须超过0.1 |
| 平均精确率 | Average Precision / AP | 汇总不同排名门槛下的精确率表现，不是准确率 |
| ROC-AUC | ROC-AUC | 衡量正样本通常能否排在负样本之前；0.5近随机 |
| 轮廓系数 | Silhouette score | 看每个点与本群和其他群的距离关系；偏好某类几何结构，不直接证明业务价值 |
| 调整兰德指数 | ARI | 比较两次分组的一致程度，不要求群编号相同；接近1表示一致，不是预测准确率 |
| 品类提升倍数 | Category lift | 群内买过某品类的比例／整体对应比例；是观察关联，不是营销增量 |
| 概率校准 | Calibration | 模型给出10%的一批人，实际是否约有10%发生目标事件 |
| 混杂因素 | Confounder | 同时关联两个现象的其他因素，例如购买次数会影响“买过某品类”的机会 |
| 因果效果 | Causal effect | 采取一个行动相较不采取，究竟造成什么变化；相关性不能替代 |
| 营销增量 | Uplift | 因营销才新增的购买，不是所有被选中且后来购买的人 |
| 对照实验 | Controlled experiment | 用实验组与对照组比较措施效果，随机分配有助于减少其他差异 |

## 三句话自查

1. “只有3%客户出现过第二单，所以97%客户流失了。”——不成立，观察窗口与平台覆盖不同。
2. “模型选中73个复购者，所以营销新增73单。”——不成立，没有干预对照。
3. “聚类轮廓系数高，所以营销一定更有效。”——不成立，几何结构与实际经营收益不是同一件事。
