# 六章结构与23页预算

本人已认可单栏IEEEtran课程样式。教师ProjectTemplate第4页给六章；报告指南第2页要求封面、一页执行摘要、图表在正文、附录参考文献计页。这里把现有修补材料组织为同一份23页报告；页数包括图表，是合稿预算。

|部分|页数|内容与主写|
|---|---:|---|
|Cover Page|1|6号合稿，六人核本人姓名/学号|
|Executive Summary|1|6号最后写，概括业务/数据/结果/建议|
|I. Introduction|1|6号：Olist背景与研究对象|
|II. Problem Statement|1|6号：有限名额名单主线、分群辅助问题|
|III. Data Description and Preparation|5|III-A来源/粒度、III-B样本/时间/标签、III-C清洗/字段可得性由1号；III-D EDA和候选字段由2号|
|IV. Methodology|3|IV-A共同预测管线/模型由3号；IV-B分群由4号；IV-C验证设计/指标/不确定性由5号|
|V. Experiment and Discussion|6|V-A基线与群模型由3号；V-B新字段由2号；V-C后期检查由5号；V-D群覆盖由4号；V-E概率/价值独立扩展由6号|
|VI. Conclusion|3|VI-A业务建议、VI-C局限/后续决策由6号；VI-B内容试验提案由4号；5号核结论强度|
|Appendix — References|2|各人交其引用与支持位置，6号合并排序|
|合计|23|正式整体20–25页|

各章可以有多个作者，按指定子节交件，6号统一过渡和编号。正文不按六个人拆成六块互不连接的论文。Introduction说背景，Problem Statement把背景收紧为可评价问题；Conclusion包含教师强调的模型如何支持业务行动。

主线仍为复购名单；概率/价值是V-E独立扩展。23页不强制塞满所有旧图，保留直接支持论点的表图；原10图和45行registry是素材与证据。完整历史实验可链接附属材料，核心比较条件、主要数据与必要结果写在正文。
