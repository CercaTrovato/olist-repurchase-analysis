# 第三轮后续公开汇总与图表

[本批解释](../../docs/team/round-3-extension.md) · [全部素材](../../docs/team/visual-assets.md)

本目录含11个新候选及6个既有对照的共同诊断、全部新方法聚合表、5幅PNG/SVG和可移植绘图脚本。训练为2017-10-01，一月为已见开发验证。四月不参与本批方法选择。

运行 python render_figures.py 可由 chart-data/ 重建五图。环境 Python、numpy、pandas、matplotlib，SVG保留文本，PNG为240dpi。公开目录仅含聚合结果与绘图源码，模型训练、逐人分数、原始核验与模型文件保存在组内版本化研究包。

图14比较浅树输入与权重，15比较卖家与交易信息，16比较固定融合/群模型，17给11个新增方法的条件区间，18给17个方法的全局与固定久单诊断。英文图配中文图注，图18的坐标是两个分开排名条件下的观察差异。当前候选区间均未证明稳定优越。

data/ 按 nonlinear、context、strategies 保存完整指标、群汇总、名单变化、条件区间及相关训练统计。context 的卖家统计只用历史并排除当前买家；支付与商品静态时点仍有假设。图17区间未包含模型搜索和未来时间泛化。
