# Six Sigma · 成员任务包

2026-11-07｜6 号已定方向。主线是给电商运营经理做有限名额的复购候选名单，分群后补充按群测试内容主题。正式分析从统一客户快照和评估设计开始。历史探索记录可参考。

## 怎么用

1. 打开自己岗位的 Markdown。交给 Agent 时一并提供本仓库、[交接协议](protocol.md) 和你实际收到的上游文件。若只转发单个文件，保留其中的协议入口。
2. 先在团队群按岗位回报已有版本、当前缺件和可交时间。实际交接在组内固定记录，发方提交版本，收方核对后回执。
3. 正式结果以双方确认的输入版本为准。原始数据及旧实验保留；新输出在本地 `outputs/`，逐行分析表在组内私有空间交接。
