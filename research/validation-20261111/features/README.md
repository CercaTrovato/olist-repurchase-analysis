## 字段、时点和信息边界

9 表 52 个字段位置全部登记于 `field-catalog-52.csv`：{'assumption': 23, 'included': 15, 'key': 10, 'redundant': 3, 'unknown_at_t': 1}。类别是每个原字段的主要处置，不表示 52 列全部进入 X。完整结构是 141 个历史摘要原始列，8 个类别；LR 编码后 913 维；文本词表训练拟合 1317 项，合计 2230 维。大量列是均值/最大/标准差、缺失标志、稀有类别或其他冗余，不能把维度解释为独立信息量。

保留 H02 冗余 AOV、max、observed days。客户和订单标识只连接；商品/卖家 ID 转为截止日前历史频率和去重数。原订单最终状态无状态日志，排除；英文分类翻译和 geo 城市/州重复标签排除。买卖家邮编类别、城市、州保留，geo 先 exact 去重再按邮编 median lat/lng，Haversine 6371.0088 km；均值是历史 item 加权，末单距离为末单各 item 均值，不是准确门牌路线。

静态商品/买家/卖家/geo 维度没有变化日志；支付、预计送达和发货截止没有回写日志。相关摘要明确依赖“审批时已知、后续未改写”的假设，不能认证严格生产时点可恢复。所有实际承运、实际送达和评价答复严格 `<t`，负时长不纳入。Oct / Jan 分别排除截止后评价 2063 / 2863 条、未来实际送达 1543 / 2439 单；评价文本仅合法已答历史，词表只 fit Oct。

原 F 全部逐键相同；M 最大误差 1.14e-13。两期所有 H02 客户键保留。Geo 原 1000163 行，经 exact 去重和经纬度合法过滤后 738332 行，聚合 19015 邮编；Oct / Jan item 距离缺失 141 / 199 条，缺失未当作零公里。

## 文件与复用

`private/october-features.csv` 和 `private/january-features.csv` 是可复用、逐键对齐原始表，包含标签 y 和独立文本。`feature-views.json` 给 141 列名单、六个逻辑视图、每列定义、类型、时点和预处理；仅使用 views 中列名构建 X。y、cluster_id、cluster_version、keys 和 past_review_text 不进入结构 X。邮编必须按 categorical_columns 读取为字符串。Oct / Jan 的 sparse NPZ 使用同一个 Oct 拟合变换，可供固定预算下游对照；原始表供折内重新拟合，不能先全量编码后做交叉验证。

`january-metrics.csv` 含自然概率质量、0.5 混淆/precision/recall/F1；`january-capacity.csv` 含 K2937、5%（1469）、20%（5874）、久单79。`calibration-bins.csv` 保存固定十分箱概率校准分布。私有模型、文本词表、填补/缩放/OHE 参数、矩阵和逐人分数均保留。源码 `run_features.py` 同时生成 PNG/SVG；`finalize_features.py` 独立核读逐人指标和导出矩阵模型分数、回源重建旧缓存15字段。
