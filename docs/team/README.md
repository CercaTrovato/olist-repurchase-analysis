## 现在各自往哪走

| 岗位 | 先打开 | 当前重点 |
|---|---|---|
| 1 号 数据与样本 | [岗位卡](role-01-data.md) | 核定评价窗口，维持统一键、标签和版本 |
| 2 号 整体 EDA 与特征 | [岗位卡](role-02-eda.md) | 和 4 号给一项可在当时计算的候选特征 |
| 3 号 监督预测 | [岗位卡](role-03-prediction.md) | 补四月评分与冻结证据 |
| 4 号 无监督分群 | [岗位卡](role-04-segmentation.md) | 找久单群内差异，补分群复跑入口 |

表中列的是下一轮建议，具体改动和采纳以 [当前进度页](current-status.md#当前可并行推进的事) 为准。时间见 [协作指南](../07-team-guide.md#倒排计划)。

## 把岗位卡交给 AI

把岗位 Markdown、交接协议和自己收到的实际输入一并交给 AI 工具。先让它说清要交哪些文件、缺什么，再跑样例并核对结果。发送交接时写清收方、文件、数据和代码版本、核过的项目。接收方核完回执。逐行客户表留在组内，公开仓库放经检查的文档和汇总。
