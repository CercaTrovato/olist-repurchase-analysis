## 4. 项目主线：PPT到底要讲什么

**业务问题：** 给全体合资格老客户估计未来90天复购概率，再帮助运营在有限关注人数下选择名单；若目标改为商品金额，名单规则也可能不同。模型预测“谁可能买”，没有证明“联系谁会额外多买”，所以不能称营销增量、利润或优惠券因果效果。

**数据：** Olist历史订单；一行是“客户×预测日”。使用预测日前六个自然月的信息，标签是之后90天是否出现正商品额的合格已批准订单。所有合资格客户都评分，10%只截输出名单；也已有1/2/5/10/20/50/100%容量结果。

**分析顺序：** 分群发现漏判与覆盖问题 → 群内分析提出字段假设 → 回全体客户作受控比较 → 评估概率和名单 → 检查跨期/组件反例 → 比较经理的不同目标与容量。B保留A的已有成果并深化这条链，贡献按实际执行记录列示。

**分群的作用：** 诊断漏判、提出特征、解释名单覆盖；不是自动保证预测更准，也不是已证明三群为天然最优。久单群是历史多为只买一次、距最近购买较久的一群；135天是群内R中位数，不能说该群所有客户恰好135天前只买过一次。
