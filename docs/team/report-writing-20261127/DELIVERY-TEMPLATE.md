# 统一交件方式（不要求LaTeX）

每人一个英文目录role-01至role-06。交给6号本人统一融合；用Word或Markdown写英文草稿，中文疑问另列。正文先说明问题和方法，再给有证据的结果与业务解读。按子节写，不需要自行排成最终几页。

## 文件

1. draft.docx或draft.md：按岗位卡子节，英文完整段落，附可编辑公式。
2. tables.xlsx或tables.csv：表格底数据，列头/单位/样本/精度/条件清楚。
3. figures/：实际采用图的PDF/SVG、PNG预览、可编辑绘图源与数据；使用现成图就写清原路径与必要标签调整。
4. assets.csv：asset_id、kind、filename、source_file、run_id、window、N、K、unit、caption、referenced_by、author、checked_by、check_status。没有实际核验的人/状态留空或pending。
5. references.csv或references.bib：citation_key、作者/题名/期刊/年份/卷期/页码、DOI、DOI URL、出版者URL、支持哪句、已读位置、阅读范围与核对日期。软件/数据来源明确类型。
6. open-questions.md：尚未解决的问题、缺证据及对正文影响；没有问题写“无新增问题”，不要伪造确认。

## 初稿标记

正文可写Figure [F01]、Table [T-R1-01]、Equation [E-R3-01]以及citation [saito2015]，在assets/references清单有对应项。它们是合稿用稳定ID，最终由6号变成自动Figure 1／Table I／Equation (1)及[1]。Word也可用交叉引用字段，无需组员学习LaTeX。
