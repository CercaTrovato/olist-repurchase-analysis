# 仅簇成员预测头的优化充分性控制

12格预定控制完成，未重训任何表征或聚类。触发依据是原50epoch头在fit上的训练不足，而非一月选优：从保存旧模型重新算出的最终fit BCE为0.081463–0.168617，全部高于fit常数0.0559255。保持同一成员／标签后，固定C1高精度LR头的fit BCE降至0.055236–0.055551，全部低于常数。因此旧raw概率很差不能直接归因于表征。

新控制也没有证明深聚类普遍优于RFM。新RFM-soft的Jan AP均值0.033622、全局固定2937命中49；deep-soft为0.022199、47.33。但RFM-soft在权威久单79中为0命中，deep-soft为1。概率、全局排序、久单策略仍有取舍，不据这次已见一月结果直接更换最终模型。

## 冻结输入和求解口径

- fit16928／169、cal4232／42，成员顺序由P4C原 `october-split.csv` 中fit/cal行序确定；标签与保存matrix.npz逐行一致。Jan源CSV29368／230全量评分，群字段与权威H05逐键一致，久单固定12330／90，未用新群号替换。
- 只读原36个 `{rfm,deep}-{hard,soft}-{seed}-{fit,cal,january}-memberships.npy`，不重新计算成员，不拟合新标准化、编码器、K或KMeans。
- 每格一次未加权LR：C1、lbfgs、tol1e-10、max_iter5000、fit_intercept=True；cal仅作无权重Platt（C1e6，tol1e-10，max_iter2000），Jan不参与拟合或选择。
- 旧头没有L2，新LR加C1正则；本项是按预定规格的高精度凸头控制，不把所有差异归为纯迭代次数。重要训练事实是同一成员可取得比常数更低的fit BCE；不能再把旧优化不足的raw LL当成表征能力上限。
- 新头22–24iter，无训练或Platt warning。实际mean梯度最大值2.20e-12–2.56e-9，12格中7格达到请求1e-10，5格未达到；所有实际梯度、目标、迭代均保存，不把请求tol冒称梯度认证，也不据此继续扩大搜索。
- 所有新Platt斜率为正，实测与新raw的K2937名单变化均0。旧raw容量严格用旧保存logit；新raw用新logit；新Platt单独用自身概率排序。不要把旧P4C的“Platt指标＋固定raw名单”规则与新校准后策略混称。
- cal Platt指标使用同一cal标签再代入，只作诊断；fit指标只说明优化。没有新增OOF或真正未见时间测试，所有一月比较继续保留已见开发窗口限制。

本P4C的RFM参考对R/F/M全做log1p，与H05/P4A的R原值、logF/logM口径不同；表中RFM vs deep是这组冻结成员之间的控制，不冒称H05复现，也不把与其他矩阵的差异直接归因深表示。容量小、正例少，以上seed范围不是时间泛化置信区间。
