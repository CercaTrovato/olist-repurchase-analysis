## 原方法与当前任务的区别

| 原论文机制 | 已核含义 | 在复购任务中的待验证设计 |
|---|---|---|
| 多视图编码与融合 | 每个视图编码成表示，全局可学习softmax权重融合，pp.4–5，Eq.3–4 | 购买行为、服务体验、卖家/地理可作为候选视图；不同维度、缺失与信息质量需先处理 |
| 困难样本处理 | 置信/不确定性、伪簇与局部结构帮助筛查和重加权对比负样本，pp.5–8 | 验证是否减少错误对比关系，再测最终真实标签预测；不能仅看聚类图更分开 |
| 少数簇原型增强 | 由共识潜空间的伪簇均值/协方差生成伪表示，并有边界/分布/质心约束，pp.8–10，Eq.30–43 | 少数行为簇不等于y=1复购类，潜向量需有明确的训练用途和标签来源 |
| 分层对比目标 | 实例层、簇层与质心一致性共同约束，pp.10–12 | 与监督BCE头的连接应独立设计，比较冻结表示与联合微调 |
| 簇数设置 | 论文实验在已知基准类别数的设置下聚类；已核train.py从基准标签取类别数 | Olist的行为簇数应由训练侧设计与评价，不自动取二元标签数2或沿用3 |

全局视图权重可学习，并不自动等于逐样本、逐字段动态注意力。本轮未在明确融合公式及所核network.py中确认这类attention实现；注意力将作为Q08的单独候选定义。

## 两条可分开的迁移路线

路线一先用训练X学习无监督/自监督表示及少数伪簇增强，再冻结编码器，把真实训练样本的表示和真实复购标签交给同一监督后端。伪原型只服务表示学习阶段。这个设计先检验表示是否对下游有用。

路线二把生成模块改为由真实训练正例条件引导的潜空间增强，并说明伪样本的类别可信度、范围及与真实样本的权重。该方案改变了原论文的无监督设置，应作为改造方法单列。两条路线都在训练折内完成，验证保持自然比例。

若采用软群归属或用户提出的群内统计初始化，需另外说明群归属来自X还是训练y，统计关系如何收缩为可学习初值，以及如何与共享输出层衔接。聚类簇大小、复购类别比例及对比batch的正负样本比例分别登记。

## 待开测的最小组件矩阵

| 设计 | 要回答什么 |
|---|---|
| 共同输入＋原后端 | 作为可比基线 |
| 无增强编码表示＋同后端 | 表示学习本身是否有价值 |
| 加困难负样本处理 | 减少错误对比关系是否帮助下游 |
| 加少数簇原型增强 | 簇增强是否帮助真实复购预测 |
| 加对齐/质心一致性 | 约束是否有额外收益 |
| 注意力或群分支另加 | 新模块收益能否分清 |
| 冻结表示与联合微调 | 无监督几何与监督目标如何配合 |

正式系统消融按用户要求在选定候选后执行。当前矩阵只是设计，全部状态为未开始。下游主指标需先经用户审阅确认，簇质量与二元预测质量分别报告。
