截至 2026-11-10，这里汇总团队交件、已见四月回测和独立本地探索。按 H02–H06 顺着看，可以从客户样本走到验证名单和各群漏判。

## 团队实际交付

| 编号 | 对照文件 | 怎样读 |
|---|---|---|
| H02 | [三期样本与覆盖](h02-cohorts.csv) | 每行一个分析日。训练 21,160 人中 211 人复购，验证 29,368 人中 230 人复购，四月按已见窗口回测记录。 |
| H03 | [月度订单覆盖](h03-monthly-coverage.csv) | 每行一个月份，分开统计下单、批准和合格批准事件。2018 年 9 月记录很少，尾部窗口要核覆盖。 |
| H04 | [验证名单比较](h04-ranking.csv) | 每行一个方法，四种方法各取 2,937 人，团队首轮逻辑回归命中 46，最近购买优先命中 30。新版加权结果在 H06 前后对照里。 |
| H05 | [三群画像](h05-cluster-profile.csv) · [初始化稳定性](h05-stability.csv) | 每群先看人数和历史特征。稳定性表只记录更换种子的结果。 |
| H06 | [三个群的验证误差](h06-segment-errors.csv) | 全局名单按群拆分。群 1 有 90 位复购者。另见 [H06 加权前后对照](h06-weighting-comparison.csv)，含逐群名单人数、命中和漏判。 |

分群画像中，久单群过去买过运动休闲品类的有 1,114／12,330 人，整体验证客户为 2,499／29,368。约 9.03% 对 8.51%，差距较小，可以据此提出内容试验，响应要另测。[品类人数与分母](h05-category-example.csv)

4 号已补交分群脚本和复跑说明。复跑的一月 29,368 个群号与原交接逐键一致。
